# Assets note

This project is built to be playable and stable even before importing exported PNG assets.

## Suggested drop-in folders
- `assets/ui/`
- `assets/characters/`
- `assets/obstacles/`
- `assets/powerups/`
- `assets/backgrounds/`
- `assets/effects/`

You can later replace the drawn canvas shapes and emoji placeholders with the exact supplied art without changing the game architecture.
