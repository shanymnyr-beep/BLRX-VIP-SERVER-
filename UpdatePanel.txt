
وصف تحديث

أنشئ تطبيق Android احترافي باسم BLRX X JODX Proxy يعمل بالكامل على AIDE Pro بدون
 أي أخطاء بناء أو توافق، ويستخدم Java + JNI (C++) + Android NDK مع دعم Shizuku.

واجهة البداية

عند تشغيل التطبيق:

يظهر شعار BLRX X JODX كما هو متفق عليه سابقًا بدون أي تغيير.

بعد انتهاء شاشة الشعار تظهر صفحة تسجيل الدخول.

تحتوي الصفحة على خانة إدخال مفتاح فقط.

لا يتم طلب أي صلاحيات Shizuku في هذه المرحلة.


نظام المفاتيح

يعتمد التطبيق على مفتاحين رئيسيين فقط:

BLRX-JODX-1105

BLRX-MOD-0808


يجب تشفير المفاتيح داخل التطبيق بتشفير قوي وعدم حفظها كنصوص صريحة داخل ملفات Java
 أو C++، مع استخدام عدة طبقات من إخفاء السلاسل (String Obfuscation) والتحقق الداخلي
 حتى يصعب استخراجها أو تعديلها.

عند إدخال مفتاح صحيح:

يتم حفظ حالة تسجيل الدخول محليًا.

ينتقل المستخدم تلقائيًا إلى صفحة التحقق من Shizuku.


أما إذا كان المفتاح غير صحيح:

تظهر رسالة خطأ أنيقة دون إغلاق التطبيق.


---

صفحة Shizuku

بعد نجاح تسجيل الدخول فقط:

يتحقق التطبيق من وجود Shizuku.

إذا لم يكن مثبتًا أو غير مشغل يعرض رسالة واضحة.

إذا كان مثبتًا يطلب صلاحية Shizuku.

بعد منح الصلاحية تظهر علامة نجاح ورسالة خضراء:


Shizuku Connected Successfully

ثم يتغير زر التشغيل إلى:

START


---

الخدمة العائمة

عند الضغط على START:

تبدأ خدمة Foreground Service.

تظهر أيقونة دائرية عائمة قابلة للسحب.

تبقى ظاهرة فوق التطبيقات حتى يتم إيقافها يدويًا.

الضغط على الأيقونة يفتح القائمة الرئيسية.

الضغط خارجها يغلقها مع بقاء الأيقونة.

Native Bridge

إنشاء طبقة NativeBridge بين Java و C++.

كل زر داخل التطبيق يستدعي دالة JNI مستقلة.

ولا يتم تنفيذ أي وظيفة إلا بعد الضغط على المستخدم.
