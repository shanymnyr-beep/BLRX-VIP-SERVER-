# ألغاز العرب

مشروع لعبة ألغاز كلمات عربية جاهز للتشغيل على AIDE Pro.

## التشغيل

1. افتح AIDE Pro.
2. أنشئ Android App Java جديد.
3. استخدم package name:

```text
com.blrx.alghazarab
```

4. انسخ الملفات بنفس المسارات الموجودة في هذا المستودع.
5. شغّل Run.

## الميزات

- صفحة رئيسية عربية فخمة.
- 30 مرحلة جاهزة.
- فتح مراحل بعد الفوز.
- نظام عملات وتلميحات.
- حفظ تلقائي عبر SharedPreferences.
- بدون مكتبات خارجية أو Android Studio.
